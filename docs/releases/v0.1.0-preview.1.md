# Web Agent Gateway Native Host 0.1.0 Preview - UNSIGNED

**UNSIGNED PREVIEW - NOT AUTHENTICODE TRUSTED**

This is a pre-signing Windows preview of the Web Agent Gateway native host.

It is intentionally **unsigned** and is **not** a Windows-trusted or Smart App Control-ready release. It exists to publish the exact Windows release form while the project prepares its open-source code-signing path.

## Scope

The Browser Inspect v2 native-host path is read-only and exposes exactly:

- `health`
- `workspace.open`
- `repo.search`
- `repo.snapshot`
- `file.read`

It does not expose raw shell/process access, Git writes, file mutation, browser mutation, or generic forwarding.
